# Softmax、温度与随机采样

[打开在线实验](https://wuchen2018.github.io/llm-engineer-book/demos/softmax/)

配套大模型书第5.2节和第13.1节。沿用第5.2节的五个候选词及分数：好3.2、差0.8、的1.5、了0.3、不−0.5。

先看Softmax怎样把分数算成概率，再调整温度，按当前概率抽一次或1000次。展开计算说明可以跟着“好”这个词算一遍；展开Top-k与Top-p可以先筛选候选词，再比较抽样结果。

本实验使用教学分数，不调用真实模型。这里公开的是独立制作的交互演示，书中其余配套代码仍按出版安排公开。

页面不需要安装Python，也不依赖外部脚本。开发时在仓库根目录运行 `python -m http.server 8000`，浏览器访问 `http://localhost:8000/demos/softmax/`。
