这是本书的作者公开资料仓库，提供书籍介绍、出版进度和样章。

## 关于这本书

一本从基础工具、数学和深度学习讲起的大模型工程书，覆盖 Transformer、训练与微调、RAG、数据工程、推理部署，也讨论求职和实际工作中的问题。

通过具体例子、推导和代码，把大模型原理与工程实践串起来。
